# Agent instructions

## Project tracking

Project tracking: STATUS.md at the repo root is the shared record Wally (Adam's assistant) reads. Update it at the end of every work session AND whenever a build is uploaded or submitted or a store status changes — not only when code changes. Keep the sections in their standard order. Put anything that needs Adam in the Needs testing or Blockers sections in plain words. Put questions for Wally in the For Wally section; Wally replies there or on the relevant pull request. Never remove the For Wally section.
